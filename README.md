# 🛒 Olist E-commerce Business Analysis

## 📖 Project Overview

This project presents an end-to-end Business Intelligence and Data Analytics solution using the Brazilian Olist E-commerce dataset. The objective was to transform raw transactional data into meaningful business insights by applying data validation, SQL analysis, and interactive Power BI visualizations.

The project demonstrates a complete analytics workflow, including database design, SQL querying, business analysis, and dashboard development.

---

## 🎯 Project Objectives

- Understand the overall performance of the Olist marketplace.
- Analyze customer purchasing behaviour.
- Measure sales and revenue trends.
- Evaluate seller and product performance.
- Examine payment methods and customer review patterns.
- Build an interactive Power BI dashboard for business decision-making.

## 💡 Key Business Insights

- Generated over **9 Million** in total revenue.
- Processed approximately **54,000** customer orders.
- Served nearly **99,000** unique customers.
- Marketplace includes over **3,000** active sellers.
- Average Order Value is approximately **161**.
- Average customer review score is **4.1 / 5**, indicating strong customer satisfaction.
- São Paulo generated the highest revenue among all customer states.
- Most customer reviews received the highest rating (5 stars).
