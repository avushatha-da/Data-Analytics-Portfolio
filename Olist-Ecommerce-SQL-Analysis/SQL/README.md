# SQL Scripts

## Description

This folder contains all SQL scripts used throughout the Olist E-commerce Business Analysis project.

The scripts are organized according to the complete analytics workflow, from database creation to advanced business insights.

---

## SQL Modules

| File | Description |
|------|-------------|
| 01_Database_Creation.sql | Creates the project database |
| 02_Table_Creation.sql | Creates all dimension and fact tables |
| 03_Data_Import.sql | Imports CSV files into MySQL |
| 04_Data_Validation.sql | Validates imported data for completeness and quality |
| 05_Business_Understanding.sql | Calculates key business KPIs |
| 06_Exploratory_Data_Analysis.sql | Performs descriptive data exploration |
| 07_Advanced_SQL_Analysis.sql | Uses joins, CTEs, subqueries and window functions |
| 08_Business_Insights.sql | Answers business questions and generates insights |
| 09_Views_and_Stored_Procedures.sql | Creates reusable SQL views and stored procedures |
| 10_Dashboard_KPI_Queries.sql | SQL queries supporting Power BI dashboard development |

---
