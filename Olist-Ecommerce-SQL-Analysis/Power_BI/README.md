# Power BI Dashboard

This folder contains the interactive Power BI dashboard developed using the Olist E-commerce dataset.

Dashboard Features

- KPI Cards
- Monthly Revenue Trend
- Top Customer States
- Product Category Revenue
- Review Score Distribution
- Date Slicer
- Customer State Filter
- Payment Type Filter

KPIs Included

- Total Revenue
- Total Orders
- Total Customers
- Total Sellers
- Average Order Value
- Average Review Score

Purpose

The dashboard enables business users to monitor marketplace performance, customer behaviour and sales trends through interactive visualizations.
