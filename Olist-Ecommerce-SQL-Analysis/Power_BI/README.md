# 🛒 Olist E-commerce Business Analysis

## Project Overview

This project analyzes the Brazilian Olist E-commerce dataset to uncover sales trends, customer behavior, seller performance, payment preferences, and product performance.

The project demonstrates an end-to-end Data Analytics workflow using SQL and Power BI.

---

## Project Objectives

- Analyze overall business performance
- Measure revenue and order trends
- Identify top-performing products and categories
- Evaluate seller performance
- Understand customer purchasing behavior
- Visualize business insights through an interactive dashboard

---

## Tools Used

- MySQL
- SQL
- Power BI
- Power Query

- GitHub

## Dataset

Brazilian Olist E-commerce Public Dataset

Records include:

- Products
- Sellers

## Key Business Insights

- Revenue exceeded **9 Million**.
- More than **54K orders** were placed.
- Nearly **99K customers** made purchases.
- Over **3K sellers** participated in the marketplace.
- Average Order Value is approximately **$161**.
- Average customer review score is **4.1/5**, indicating high customer satisfaction.
