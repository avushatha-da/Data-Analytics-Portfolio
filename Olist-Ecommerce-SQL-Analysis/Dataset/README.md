# Dataset

This folder contains the cleaned CSV files used for the Olist E-commerce SQL Analysis project.

The dataset includes customer, seller, product, payment, review, order and geolocation information.

Source

Brazilian E-commerce Public Dataset by Olist.

Files

- dim_customers.csv
- dim_products.csv
- dim_sellers.csv
- dim_geolocation.csv
- fact_orders.csv
- fact_order_items.csv
- fact_payments.csv
- fact_reviews.csv
- product_category_translation.csv

These files were cleaned in Power Query before importing into MySQL.
