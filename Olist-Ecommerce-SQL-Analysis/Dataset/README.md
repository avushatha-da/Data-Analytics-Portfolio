# 📂 Dataset

## Description

This folder contains the datasets used for the Olist E-commerce Business Analysis project.

The data was obtained from the Brazilian Olist E-commerce Public Dataset and organized into dimension and fact tables for analysis.

---

## Files Included

| File Name | Description |
|-----------|-------------|
| dim_customers.csv | Customer information |
| dim_geolocation.csv | Customer and seller geographical data |
| dim_products.csv | Product details |
| dim_sellers.csv | Seller information |
| fact_orders.csv | Order details |
| fact_order_items.csv | Products purchased in each order |
| fact_payments.csv | Payment transactions |
| fact_reviews.csv | Customer review data |
| product_category_translation.csv | Portuguese to English product category mapping |

---

## Notes

- Original dataset cleaned using Power Query.
- Imported into MySQL for SQL analysis.
- Used in Power BI for dashboard creation.
