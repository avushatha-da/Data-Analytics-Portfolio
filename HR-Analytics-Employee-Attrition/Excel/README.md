# Excel Data Cleaning

## Objective

Prepare the HR Employee Attrition dataset for SQL analysis by validating data quality and performing essential cleaning operations in Power Query.

---

## Cleaning Steps Performed

- Imported dataset into Power Query
- Verified data types
- Checked for missing values
- Checked duplicate employee records
- Removed constant columns:
  - EmployeeCount
  - Over18
  - StandardHours
- Validated categorical values
- Validated numeric fields
- Exported cleaned dataset

---

## Result

Rows Before Cleaning : 1470

Rows After Cleaning : 1470

Columns Before Cleaning : 35

Columns After Cleaning : 32

No duplicate records were found.

No missing values were found.

Dataset is ready for SQL analysis.
