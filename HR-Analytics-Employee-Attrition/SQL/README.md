# HR Employee Attrition Analysis — SQL

## Summary

This folder contains the complete SQL analysis for the HR Employee Attrition Analysis project.

The analysis uses MySQL to validate employee data, calculate key HR KPIs, explore employee attrition patterns, apply advanced SQL techniques, generate business insights, and create reusable SQL views and stored procedures.

The SQL workflow progresses from database creation and data import through business analysis and advanced SQL techniques, providing a structured foundation for the final Power BI dashboard.

### Key Areas Covered

- Employee and workforce analysis
- Employee attrition analysis
- Department and job role analysis
- Overtime and business travel analysis
- Salary and age analysis
- Job satisfaction and work-life balance analysis
- Exploratory Data Analysis (EDA)
- CTEs and Window Functions
- `RANK()` and `DENSE_RANK()`
- Conditional aggregation and `CASE` statements
- SQL Views
- Stored Procedures
- Business insights and HR recommendations
